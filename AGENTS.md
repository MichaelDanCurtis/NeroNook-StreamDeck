# Stream Deck module

Build independently of NeroNook and other plugins. Keep device I/O, profile data, imports, actions, permissions and configuration here. Use the versioned generic NookPluginSDK only when adding host presentation. The host must remain usable with no plugins.

Current milestone: read-only profile inventory and compatibility foundation. Never overwrite Elgato profiles, import credentials into reports, invoke imported actions, claim working plugin compatibility from parsing, or seize hardware while the existing owner is active. Profile names, user text, URLs and action settings do not belong in the aggregate audit report.

Use original UI assets. Reused open-source adapters require pinned provenance and license notices. Do not redistribute installed Elgato or marketplace binaries/artwork. Run scripts/test.sh and an explicit read-only audit before recording acceptance. Hardware output and button/dial execution are separate gates.
